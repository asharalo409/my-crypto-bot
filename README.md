# ⚡ CYBERPUNK NEON DCA TRADING BOT

একটি অটোমেটেড ক্রিপ্টো স্পট ট্রেডিং বট যা Binance API ব্যবহার করে পরিচালিত হয়। এটিতে সাইবারপাঙ্ক নিয়ন UI, ট্যাকটিক্যাল রাডার স্ক্যানার এবং ডিপে স্বয়ংক্রিয় এভারেজিং (DCA) সিস্টেম যুক্ত রয়েছে।

---

## 🚀 প্রধান বৈশিষ্ট্যসমূহ (Features)

* **Cyberpunk HUD & Tactical Radar:** রিয়েল-টাইম মার্কেট স্ক্যানিং ও নিয়ন ভিজ্যুয়াল ইন্টারফেস।
* **DCA Engine (ডিপে বাই):** দাম কমে গেলে গড়ে আনার জন্য ধাপে ধাপে বাই (Dollar-Cost Averaging) এবং নির্ধারিত লাভে একযোগে সেল।
* **No-Loss Mode:** লাভ নিশ্চিত না হওয়া পর্যন্ত বট কোনো পজিশন লসে সেল করবে না।
* **Multi-Pair Support:** BTC, ETH, SOL, BNB, XRP, ADA, DOGE, AVAX সহ প্রধান ৮টি পেয়ার ট্র্যাকিং।
* **Telegram Integration:** তাৎক্ষণিক বাই/সেল ও প্রফিট নোটিফিকেশন।
* **24/7 Cloud Ready:** Render, Railway বা যেকোনো ক্লাউড সার্ভারে বিরতিহীন চলার উপযোগী।

---

## 🛠️ ক্লাউড কনফিগারেশন (Render Setup)

* **Build Command:** `pip install -r requirements.txt`
* **Start Command:** `python bot.py`
* **Environment:** Python 3

---

## ⚠️ সতর্কতা

এটি ব্যক্তিগত ব্যবহারের জন্য তৈরি একটি অ্যালগরিদমিক ট্রেডিং বট। লাইভ মার্কেটে চালানোর আগে পর্যাপ্ত পরীক্ষা (Demo Mode) এবং ঝুঁকি বিবেচনা করে ব্যবহার করুন।
